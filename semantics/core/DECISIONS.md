- 推奨を受けるなら、項目の最初のチェックボックスにチェックを入れてください。ほかの選択肢を選ぶなら、その行にチェックを入れてください。

## 0. 頼まれた形から変えたこと

1. **1 つの表ではなく、3 つの組に分けた。** 「動き」「設計」「モデルと道具」です。#220 で作者が「モデルの粒度や CI の導入などは、動作の判断とは分けて扱う」と書いているのと、影響の大きい順（読みが消える、違う文字が入る）に並べられるのは動きの項目だけだからです。番号は 3 つの組を通して振っています。
2. **チェックボックスは表の外に置いた。** GitHub の表の中ではチェックボックスが効かないので、組ごとに一覧の表を置き、その下に項目ごとのチェックボックスを並べました。
3. **決めることは 4 か所にあった。** CORE.md の §0 に、視点そのものの直し（V7 の文言、V11 を足す）を作者に聞く点があったので、項目 18 として足しました。
