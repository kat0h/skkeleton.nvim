# かなテーブル lint

かなテーブルとキーマップの衝突を、テーブルの定義から調べる検査の仕様と結果を記録する。このディレクトリは `formal-semantics` ブランチ上の調査用であり、利用者向け機能ではない。

## 検査の定義

1. **届かない項目**：キーマップ関数が先に選ばれ、かなテーブルへ到達しない完全一致や長い項目を報告する。関数値の項目を上書きした場合も報告する。関数が入力へ戻す既知の経路は除く。
2. **前の解釈が変わる（V4）**：キー列 `x` とその真の拡張 `x·y` を、通常の入力処理とキーマップの優先順で追う。`x` の処理中に実際に確定したかなだけを比較し、そのかなが `x·y` のかな出力の先頭に残らなければ報告する。比較するのはかな文字列だけで、feed は比較しない。
3. **先読みの長さ**：入力キーを進め、結果が出るか、打ちかけが確定・破棄されるまでのキー数を数える。feed を含む有限状態グラフの、未確定のまま進む経路の最大長を報告する。未確定のまま戻る cycle があれば「上限なし」と報告する。
4. **送り仮名の切れ目（V10）**：キー列 `x` のかな出力が拡張 `x·y` のかな出力の先頭にあり、`y` の先頭キーを大文字にすると送りが始まる場合を調べる。`x` の出力末尾が、拡張側のかな単位の境界でなければ報告する。かな以外の出力は対象外。

### V10 のかな単位

作者の承認（issue #263 の回答）に従い、検査用の「かな単位」を使う。これは Unicode の書記素クラスタではない。

- 小書きかなは直前のかな単位に結合する（例：`ちゃ` はひとまとまり）。
- `っ` と `ー` はそれぞれ独立した単位とする。

テーブル出力をこの規則で分けてから、送り開始位置が出力のどの境界に対応するかを調べる。通常の文字列分割や Unicode 書記素境界と、この検査上の単位を混同しない。

## 調査対象

- 既定テーブルは `lua/skkeleton/kana/rom_hira.lua` と `rom_zen.lua`、既定キーマップは `lua/skkeleton/keymap.lua`。
- `rom_hira` には `ちゃ` など小書きかなを含む出力、`っ` と `ー` の出力がある。促音エントリには子音の feed を持つものもある。
- `rom_zen` は全角英数字・記号を出力する。V10 はかな以外の出力を数えて検査対象から外す。
- 利用者テーブルは出どころとライセンスを確認して `.tests/` に置く。辞書や利用者データは使わず、テーブルのコードはリポジトリに含めない。
- 評価した AZIK US テーブルの出典は [k16em/skkeleton-azik-kanatable](https://github.com/k16em/skkeleton-azik-kanatable)、固定コミットは `e73e49b147163d204b41aff9a65d34e2c5a75190`。同リポジトリの `LICENSE` は Copyright (c) 2023 k16em の zlib license。コードは取り込まず、テーブルデータだけ `.tests/` に抽出した。

## 結果

`nvim --headless -u NONE -i NONE -l semantics/kana-lint/lint.lua` の結果。先読み値は入力キー数。

| テーブル | 項目 | 先読み上限 | V1 | V4 | V10 | かな以外の出力 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 既定 rom | 242 | 4 | 0 | 0 | 0 | 20 |
| 既定 zen | 94 | 5 | 0 | 0 | 0 | 94 |
| AZIK US | 553 | 5 | 0 | 0 | 0 | 17 |

V3 は3テーブルとも有限だった。先読み上限は、Neovim から届く入力イベントの数で数える。普通の文字は1 codepoint を1入力、Shift+A のようなキーは1入力とする。大文字入力は `kana_input` で `<s-a>` に変換される一方、トライはキー表記のバイト列を使うため、普通の文字 `<`・`s`・`-`・`a`・`>` の5入力でも同じ `<s-a>` 項目に届く経路がある。この経路も数え、rom は最大4入力、zen と AZIK は最大5入力だった。rom の `c` と `b` のような不一致は、前の feed を破棄したあと次の feed を始めるため、同じ解釈の先読み cycle には数えない。
