はじめに                                              *skkeleton-introduction*

*skkeleton.nvim* は Neovim で SKK 方式の日本語入力を行うプラグインです。
skkeleton を Neovim 向けに Lua で再実装しています。
変換確定前の文字列（pre-edit）はバッファに直接書き込まず、extmark の仮想テキ
スト（virtual text）として表示します。確定した文字列のみがバッファに挿入され
ます。

必要なもの~

- Neovim 0.12（動作確認済み）
- SKK 辞書（SKK-JISYO.L などを展開し、|skkeleton-config-globalDictionaries|
  でパスを指定してください）

==============================================================================
インストールと最小限の設定                                 *skkeleton-install*

lazy.nvim を使う場合の設定例です。
>lua
    {
      "kat0h/skkeleton.nvim",
      event = { "InsertEnter", "CmdlineEnter" },
      config = function()
        require("skkeleton").setup({
          globalDictionaries = { "~/.config/skk/SKK-JISYO.L" },
        })
        vim.keymap.set({ "i", "c" }, "<C-j>", "<Plug>(skkeleton-toggle)")
      end,
    }
<
辞書の DB ファイルは初回使用時に自動生成されます。Neovim の起動時にあらかじめ
準備しておきたい場合は、|skkeleton-faq| の |skkeleton-faq-initialize| を参照し
てください。

Lua API                                                        *skkeleton-api*

以下の関数はすべて `require("skkeleton")` が返すテーブルから呼び出します。

                                                           *skkeleton.setup()*
setup([{opts}])
	プラグインの設定を行います。{opts} には |skkeleton-config| の各設定
	キーを指定します（`indicator` のみ |skkeleton-indicator| の設定テー
	ブルまたは boolean を指定します）。複数回呼び出すことができ、2 回目
	以降は指定したキーのみが上書きされます。
	未知のキーや型の異なる値が含まれている場合は、設定を変更せずにエラーを
	送出します。
	辞書に関する設定は、SKK を初めて有効化する前に行ってください。

                                                          *skkeleton.enable()*
enable()
	SKK を有効にします。|<Plug>(skkeleton-enable)| と同じです。

                                                         *skkeleton.disable()*
disable()
	SKK を無効にします。|<Plug>(skkeleton-disable)| と同じです。

                                                          *skkeleton.toggle()*
toggle()
	SKK の有効・無効を切り替えます。|<Plug>(skkeleton-toggle)| と同じで
	す。

                                                            *skkeleton.mode()*
mode()
	現在の入力モード名を返します。SKK が無効なときは空文字列（`""`）を返し
	ます。有効時は `"hira"`、`"kata"`、`"hankata"`、`"zenkaku"`、
	`"abbrev"` のいずれかを返します。

                                                      *skkeleton.is_enabled()*
is_enabled()
	SKK が有効であれば `true`、無効であれば `false` を返します。

                                                      *skkeleton.get_config()*
get_config()
	現在の設定テーブルを返します。読み取り用として使用し、直接書き換えない
	でください。

                                                      *skkeleton.initialize()*
initialize([{force}])
	初期化を行い、UI をブロックせずに辞書を読み込みます。DB ファイルの生成
	は非同期に分割して実行されます。{force} が真の場合は再初期化を行いま
	す。
	|skkeleton-initialize-pre| および |skkeleton-initialize-post| フックは
	初回の初期化時のみ実行されます。

                                                 *skkeleton.update_database()*
update_database({path} [, {encoding} [, {force}]])
	{path} に指定した辞書の DB ファイルを更新（再生成）します。
	- {path}: 辞書ファイルのパス。
	- {encoding}: 辞書の文字コード。省略または空文字列の場合は自動判別しま
	  す。
	- {force}: 真の場合は、辞書ファイルが変更されていなくても DB を再生成
	  します。偽（省略時）の場合は、辞書ファイルのサイズまたは更新時刻が
	  DB の記録と異なるときのみ再生成します。

                                                 *skkeleton.register_keymap()*
register_keymap({state}, {key}, {func})
	|skkeleton-kanatable-keymap| を参照してください。

                                              *skkeleton.register_kanatable()*
register_kanatable({name}, {tbl} [, {create}])
	|skkeleton-kanatable-register| を参照してください。

                                         *skkeleton.register_kanatable_file()*
register_kanatable_file({name}, {path} [, {encoding} [, {create}]])
	|skkeleton-kanatable-file| を参照してください。

なお、ステータスラインなどから呼び出せるよう、Vim script 関数として
`skkeleton#is_enabled()` と `skkeleton#mode()` も提供しています。

マッピング                                             *skkeleton-keymappings*

以下の |<Plug>| マッピングは挿入モード、コマンドラインモード、端末モードで使用
できます。SKK が有効な間は、未入力（直接入力）状態のときのみ機能します。

<Plug>(skkeleton-enable)                            *<Plug>(skkeleton-enable)*
	SKK を有効にします。

<Plug>(skkeleton-disable)                          *<Plug>(skkeleton-disable)*
	SKK を無効にします。

<Plug>(skkeleton-toggle)                            *<Plug>(skkeleton-toggle)*
	SKK の有効・無効を切り替えます。
>lua
    vim.keymap.set({ "i", "c", "t" }, "<C-j>", "<Plug>(skkeleton-toggle)")
<
SKK が有効な間は、既定で以下のキーに |skkeleton-functions| の機能が割り当てら
れています。割り当ては |skkeleton.register_keymap()| で変更できます。

input:
	<BS>      |skkeleton-functions-deleteChar|
	<C-g>     |skkeleton-functions-cancel|
	<C-h>     |skkeleton-functions-deleteChar|
	<C-q>     |skkeleton-functions-hankatakana|
	<CR>      |skkeleton-functions-newline|
	<Esc>     |skkeleton-functions-escape|
	<NL>      |skkeleton-functions-kakutei|
	>         |skkeleton-functions-prefix|
henkan:
	<C-g>     |skkeleton-functions-cancel|
	<CR>      |skkeleton-functions-newline|
	<NL>      |skkeleton-functions-kakutei|
	<Space>   |skkeleton-functions-henkanForward|
	x         |skkeleton-functions-henkanBackward|
	X         |skkeleton-functions-purgeCandidate|
	>         |skkeleton-functions-suffix|

                                                     *g:skkeleton#mapped_keys*
g:skkeleton#mapped_keys
	SKK が有効な間にバッファローカルでマッピングする対象キーを追加するため
	のリストです。キーは |<>| 表記で指定します。
	既定では英数字、各種記号、`<BS>`、`<C-h>`、`<CR>`、`<Space>`、
	`<C-q>`、`<C-j>`、`<C-g>`、`<Esc>` などが対象になっています。それ以外
	のキーに |skkeleton.register_keymap()| で機能を割り当てたい場合は、こ
	の変数にキーを追加してください。
>lua
    vim.g["skkeleton#mapped_keys"] = { "<C-l>" }
    require("skkeleton").register_keymap("input", "<C-l>", "zenkaku")
<
==============================================================================
機能一覧                                                 *skkeleton-functions*

キーに割り当て可能な機能の一覧です。機能名は skkeleton と同じです。括弧内は
利用可能な状態（state）と既定のキー割り当てを示します。

kakutei                                          *skkeleton-functions-kakutei*
	(input: <NL>, henkan: <NL>)
	入力中または変換中の文字列を確定します。未入力状態のときは、カナ入力な
	どのモードを解除してひらがなモードに戻ります。

newline                                          *skkeleton-functions-newline*
	(input: <CR>, henkan: <CR>)
	現在の入力を確定して改行します。確定後に改行を挿入するかどうかは
	|skkeleton-config-eggLikeNewline| で変更できます。

cancel                                            *skkeleton-functions-cancel*
	(input: <C-g>, henkan: <C-g>)
	現在の入力や変換をキャンセルします。キャンセル時の戻り先は
	|skkeleton-config-immediatelyCancel| で変更できます。

disable                                          *skkeleton-functions-disable*
	(input, henkan)
	SKK を無効にします。

escape                                            *skkeleton-functions-escape*
	(input: <Esc>, henkan: <Esc>)
	挿入モードまたはコマンドラインモードを抜けます。
	|skkeleton-config-keepState| が真の場合は、次回挿入モードに入った際に
	SKK が再び有効になります。

henkanFirst                                  *skkeleton-functions-henkanFirst*
	(input)
	変換を開始します。直接入力状態のときは、かなテーブルのルールに従って処
	理します。

henkanForward                              *skkeleton-functions-henkanForward*
	(henkan: <Space>)
	次の変換候補に進みます。

henkanBackward                            *skkeleton-functions-henkanBackward*
	(henkan: x)
	前の変換候補に戻ります。最初の候補からさらに戻ると、変換前の入力状態に
	戻ります。

purgeCandidate                            *skkeleton-functions-purgeCandidate*
	(input, henkan: X)
	選択中の変換候補をユーザー辞書から削除します。変換中でない場合は、直前
	に確定した候補が対象になります。削除後は未入力状態に戻ります。

henkanInput                                  *skkeleton-functions-henkanInput*
	(henkan)
	現在選択している変換候補を確定し、続けて次の文字を入力します。

kakuteiFeed                                  *skkeleton-functions-kakuteiFeed*
	(input)
	直接入力状態のときに、未確定のローマ字（「n」など）が残っていれば確定
	します。

henkanPoint                                  *skkeleton-functions-henkanPoint*
	(input)
	変換開始位置（▽）を設定します。いわゆる sticky key として使います。

deleteChar                                    *skkeleton-functions-deleteChar*
	(input: <BS>, <C-h>)
	入力中の文字を 1 文字削除します。変換開始位置まで削除すると、変換入力
	状態を解除します。

hirakana                                        *skkeleton-functions-hirakana*
	(input)
	ひらがな入力モードに切り替えます。

katakana                                        *skkeleton-functions-katakana*
	(input)
	カタカナ入力モードに切り替えます。変換入力中（▽）の場合は、入力中の文
	字列をカタカナに変換して確定します。

hankatakana                                  *skkeleton-functions-hankatakana*
	(input: <C-q>)
	半角カタカナ入力モードに切り替えます。変換入力中（▽）の場合は、入力中
	の文字列を半角カタカナに変換して確定します。

zenkaku                                          *skkeleton-functions-zenkaku*
	(input)
	全角英数入力モードに切り替えます。

abbrev                                            *skkeleton-functions-abbrev*
	(input)
	abbrev（英数変換）モードに切り替えます。

prefix                                            *skkeleton-functions-prefix*
	(input: >)
	接頭辞の入力を開始します。開始できない状態では、そのキーを通常のかな入
	力として処理します。

suffix                                            *skkeleton-functions-suffix*
	(henkan: >)
	接尾辞の入力を開始します。

==============================================================================
設定                                                        *skkeleton-config*

|skkeleton.setup()| にテーブルを渡して設定します。キー名は skkeleton と同じで
す。ファイルパスでは先頭の `~` がホームディレクトリに展開されます。
>lua
    require("skkeleton").setup({
      eggLikeNewline = true,
    })
<
acceptIllegalResult                     *skkeleton-config-acceptIllegalResult*
	(既定値: false)
	真にすると、かな変換に失敗した不完全なローマ字もそのままバッファに残し
	ます。

completionRankFile                       *skkeleton-config-completionRankFile*
	(既定値: "")
	skkeleton との設定互換性のために用意されています。型の検証のみを行い、
	実際の処理では使用しません。

databasePath                                   *skkeleton-config-databasePath*
	(既定値: "")
	辞書の DB ファイルを保存するディレクトリです。空文字列の場合は
	`stdpath("cache")/skkeleton` が使われます。指定したディレクトリ内に、
	辞書ごとの `<辞書パスのハッシュ>.db` ファイルが作成されます。
	指定したパスが既存のファイルである場合や、`skk.db` のように拡張子を持
	つ場合は、その親ディレクトリが使用されます。|skkeleton-faq-database|
	も参照してください。

debug                                                 *skkeleton-config-debug*
	(既定値: false。|g:skkeleton#debug| が真なら true)
	真にすると、入力されたキーなどのデバッグ情報をメッセージ出力します。

eggLikeNewline                               *skkeleton-config-eggLikeNewline*
	(既定値: false)
	真にすると、変換中に改行キー（|skkeleton-functions-newline|）を押した
	際に、改行を挿入せず確定のみを行います。

globalDictionaries                       *skkeleton-config-globalDictionaries*
	(既定値: {})
	使用するグローバル辞書のリストです。ファイルパスの文字列、または
	`{ パス, エンコーディング }` の配列を並べて指定します。エンコーディン
	グを省略した場合は自動判別します（EUC-JP と UTF-8 に対応）。圧縮された
	辞書は展開してから指定してください。拡張子が `.json` のファイルは
	JSON 辞書として読み込みます（YAML 形式および MessagePack 形式には対応
	していません）。
>lua
    globalDictionaries = {
      { "/usr/share/skk/SKK-JISYO.L", "euc-jp" },
      "~/.skk/SKK-JISYO.emoji",
    }
<
globalKanaTableFiles                   *skkeleton-config-globalKanaTableFiles*
	(既定値: {})
	かなテーブル定義ファイルのリストです。指定形式は
	|skkeleton-config-globalDictionaries| と同じです。
>lua
    globalKanaTableFiles = { { "/usr/share/skk/azik_us.rule", "euc-jp" } }
<
immediatelyCancel                         *skkeleton-config-immediatelyCancel*
	(既定値: true)
	真にすると、変換候補の選択中などに |skkeleton-functions-cancel| を実行
	した際、1 段階ずつ戻るのではなく一気に未入力状態へ戻ります。

immediatelyDictionaryRW             *skkeleton-config-immediatelyDictionaryRW*
	(既定値: true)
	真にすると、変換や確定のたびにユーザー辞書を読み書きします。複数の
	Neovim インスタンス間でユーザー辞書を共有する場合に有効です。

immediatelyOkuriConvert             *skkeleton-config-immediatelyOkuriConvert*
	(既定値: true)
	真にすると、送りあり変換の途中で「っ」が直接入力された時点で、タ行の送
	り仮名が入力されたものとみなして直ちに変換を開始します。ローマ字の連続
	入力で「っ」を入力する場合のように、後続の未確定文字がある場合には影響
	しません。

kanaTable                                         *skkeleton-config-kanaTable*
	(既定値: "rom")
	使用するかなテーブルの名前です。登録済みのテーブル名のみ指定できます。
	独自のテーブルを使う場合は、先に |skkeleton.register_kanatable()| など
	でテーブルを作成してください。

keepMode                                           *skkeleton-config-keepMode*
	(既定値: false)
	真にすると、SKK を一度無効にして再度有効にした際、前回の入力モード（カ
	タカナモードなど）を維持します。

keepState                                         *skkeleton-config-keepState*
	(既定値: false)
	真にすると、SKK が有効なまま挿入モードを抜けた際、次に挿入モードに入っ
	たときにも有効状態を維持します。

lowercaseMap                                   *skkeleton-config-lowercaseMap*
	(既定値: {})
	かな入力中に大文字を入力すると、対応する小文字に変換して変換開始位置を
	設定します。かなテーブルをカスタマイズして記号キーなどを割り当てている
	場合、標準の小文字変換では意図通りに動作しないことがあるため、このテー
	ブルで変換規則を指定します。
>lua
    -- AZIK で「っ」を入力するための設定例
    lowercaseMap = { ["+"] = ";", [":"] = ";" }
<
markerHenkan                                   *skkeleton-config-markerHenkan*
	(既定値: "▽")
	変換の読みを入力中であることを示すマーカー文字列です。

markerHenkanSelect                       *skkeleton-config-markerHenkanSelect*
	(既定値: "▼")
	変換候補を選択中であることを示すマーカー文字列です。

registerConvertResult                 *skkeleton-config-registerConvertResult*
	(既定値: false)
	真にすると、カタカナ変換などの結果もユーザー辞書に登録します。

selectCandidateKeys                     *skkeleton-config-selectCandidateKeys*
	(既定値: "asdfjkl")
	ポップアップ表示された変換候補を選択するためのキーです。`x` 以外の半角
	英字 7 文字を指定します。

setUndoPoint                                   *skkeleton-config-setUndoPoint*
	(既定値: true)
	真にすると、変換確定時にアンドゥポイント（|<C-g>u|）を設定します。

showCandidatesCount                     *skkeleton-config-showCandidatesCount*
	(既定値: 4)
	変換候補をポップアップ一覧で表示するまでに、インラインで 1 つずつ表示
	する候補数です。

skkServerHost                                 *skkeleton-config-skkServerHost*
skkServerPort                                 *skkeleton-config-skkServerPort*
skkServerReqEnc                             *skkeleton-config-skkServerReqEnc*
skkServerResEnc                             *skkeleton-config-skkServerResEnc*
	(既定値: "127.0.0.1"、1178、"euc-jp"、"euc-jp")
	skkeleton との設定互換性のために用意されています。型の検証のみを行い、
	実際の処理では使用しません。

sources                                             *skkeleton-config-sources*
	(既定値: { "skk_dictionary" })
	変換候補の取得元のリストです。ユーザー辞書はこの設定にかかわらず常に使
	用されます。

	"skk_dictionary":
		|skkeleton-config-globalDictionaries| に指定されたグローバル
		辞書を検索します。辞書は DB 化して高速に検索されます。
	"deno_kv":
		`"skk_dictionary"` と同じものとして扱われます。skkeleton の設
		定をそのまま引き継げるように受け付けています。
	"skk_server"、"google_japanese_input":
		対応していません。指定された場合は警告を表示して無視します。

userDictionary                               *skkeleton-config-userDictionary*
	(既定値: "~/.skkeleton")
	ユーザー辞書のファイルパスです。文字コードは UTF-8 で保存されます。

==============================================================================
かなテーブルとキーマップ                                 *skkeleton-kanatable*

                                                *skkeleton-kanatable-register*
register_kanatable({name}, {tbl} [, {create}])
	{name} のかなテーブルに {tbl} の変換規則を登録します。未作成のテーブル
	名を指定する場合は、{create} に `true` を渡す必要があります（省略時ま
	たは `false` の場合はエラーになります）。{tbl} の各キー（入力文字列）
	に対する値には以下を指定できます。
	- 文字列: |skkeleton-functions| の機能名。
	- 要素数 1 または 2 の文字列配列:
	  `{ 確定するかな, 次の入力に残す文字 }` の組。第 2 要素を省略した場合
	  は空文字列になります（`tt` で「っ」を入力し、次の入力用に `t` を残す
	  場合などに使用します）。
	- `false`: そのキーの規則をテーブルから削除します。
>lua
    local skkeleton = require("skkeleton")
    skkeleton.register_kanatable("rom", {
      hh = { "お", "h" },
      jj = "escape",
      ["z,"] = { "―" },
    })
    -- カンマ・ピリオドを全角にする
    skkeleton.register_kanatable("rom", {
      [","] = { "，", "" },
      ["."] = { "．", "" },
    })
    -- l プレフィックスで小書き文字を入力できるようにする
    skkeleton.register_kanatable("rom", {
      l = false,
      la = { "ぁ" }, li = { "ぃ" }, lu = { "ぅ" },
      le = { "ぇ" }, lo = { "ぉ" },
      lya = { "ゃ" }, lyu = { "ゅ" }, lyo = { "ょ" },
    })
<
                                                    *skkeleton-kanatable-file*
register_kanatable_file({name}, {path} [, {encoding} [, {create}]])
	ファイルに定義されたかなテーブルの規則を読み込み、{name} のテーブルに
	登録します。{encoding} を省略した場合は文字コードを自動判別します。

                                                  *skkeleton-kanatable-keymap*
register_keymap({state}, {key}, {func})
	状態（{state}）ごとのキーマップを登録します。{state} には `"input"` ま
	たは `"henkan"` を指定します。{key} には |<>| 表記のキーを指定します。
	{func} には |skkeleton-functions| の機能名、または Lua の関数を指定し
	ます。空文字列（`""`）または `false` を渡すと、そのキーの割り当てを解
	除します。
	割り当てたいキーが既定でマッピング対象になっていない場合は、
	|g:skkeleton#mapped_keys| に追加してください。
>lua
    -- 変換中の候補戻しを x から <BS> に変更する
    skkeleton.register_keymap("henkan", "<BS>", "henkanBackward")
    skkeleton.register_keymap("henkan", "x", "")
<

インジケータ                                             *skkeleton-indicator*

現在の入力モードをカーソル付近の小さなフローティングウィンドウに表示します。
skkeleton_indicator.nvim をベースに、skkeleton.nvim に内蔵しています。
|skkeleton.setup()| の `indicator` オプションにテーブルを渡すと設定を変更で
き、`false` を渡すと無効になります。省略時は既定の設定で有効になります。
>lua
    require("skkeleton").setup({
      indicator = {
        hiraText = "あ",
        border = "single",
      },
    })
<
表示色を変更したい場合は、`setup()` を呼ぶ前に |skkeleton-highlight| のハイラ
イトグループを定義するか、`*HlName` オプションで既存のハイライトグループ名を指
定してください。起動後にハイライト定義を変更した場合は、
`require("skkeleton.indicator").refresh()` を呼ぶと反映されます。なお、
|cmdline-window| では表示されません。

設定可能なオプションは以下のとおりです。

eijiHlName、hiraHlName、kataHlName、hankataHlName、zenkakuHlName、
abbrevHlName ~
	既定値: "SkkeletonIndicatorEiji"、"SkkeletonIndicatorHira"、
	"SkkeletonIndicatorKata"、"SkkeletonIndicatorHankata"、
	"SkkeletonIndicatorZenkaku"、"SkkeletonIndicatorAbbrev"
	型: string
	直接入力、ひらがな、カタカナ、半角カタカナ、全角英数、abbrev の各モー
	ドで使用するハイライトグループ名です。

eijiText、hiraText、kataText、hankataText、zenkakuText、abbrevText ~
	既定値: "英字"、"ひら"、"カタ"、"半ｶﾀ"、"全英"、"abbr"
	型: string
	各モードでインジケータに表示する文字列です。

border ~
	既定値: nil
	型: 文字列、配列、または関数
	ウィンドウの枠線を指定します。|nvim_open_win()| の `border` と同じ形式
	の値、またはそれを返す関数を指定できます。関数の場合は引数として
	`{ mode = "hira" }` のようなテーブルを受け取るため、モードごとに枠線を
	変えることができます。関数が `nil` を返すと枠線は非表示になりますが、
	枠線分の余白（1 文字分）は文字列の周囲に残ります。

row ~
	既定値: 1（border が nil、"none"、"shadow" 以外のときは 0）
	型: integer
	カーソル位置を基準とした縦方向のオフセット（行数）です。

col ~
	既定値: 1
	型: integer
	カーソル位置（pre-edit 表示中はその末尾）を基準とした横方向のオフセッ
	ト（列数）です。

zindex ~
	既定値: nil
	型: integer
	他のフローティングウィンドウと重なった際の表示優先度です。
	|nvim_open_win()| の `zindex` オプションと同じです。

alwaysShown ~
	既定値: true
	型: boolean
	真の場合は、挿入モード中に常にインジケータを表示します。偽の場合は、
	SKK が有効なときのみ表示します（直接入力時の「英字」表示が出なくなりま
	す）。

fadeOutMs ~
	既定値: 3000
	型: integer
	インジケータが自動的に消えるまでの時間（ミリ秒）です。`0` を指定すると
	フェードアウトせず、挿入モードの間常に表示し続けます。

ignoreFt ~
	既定値: {}
	型: string[]
	インジケータを表示しないファイルタイプのリストです。

bufFilter ~
	既定値: 常に true を返す関数
	型: fun(bufnr: integer): boolean
	バッファ番号を受け取り、インジケータを表示するかどうかを boolean で返
	す関数です。`ignoreFt` の判定のあとに評価されます。

useDefaultHighlight ~
	既定値: true
	型: boolean
	Neovim の既定カラースキーム使用時に、ユーザー定義のハイライトグループ
	よりプラグイン既定の配色を優先するかどうかを指定します。独自のハイライ
	ト定義を優先したい場合は `false` を指定してください。

FAQ                                                            *skkeleton-faq*

変換ができない~

変換を行うには SKK 辞書が必要です。https://skk-dev.github.io/dict/ などから
SKK-JISYO.L などの辞書を取得・展開し、|skkeleton-config-globalDictionaries| に
パスを設定してください。

初回の変換時に少し待たされる~
                                                    *skkeleton-faq-initialize*
辞書は初回使用時に読み込まれます。初回のみ辞書ファイルから検索用の DB ファイル
を生成するため、その間だけ入力が待機状態になります。Neovim の起動直後にバック
グラウンドで準備しておくには、|skkeleton.initialize()| を呼び出してください。
>lua
    vim.api.nvim_create_autocmd("VimEnter", {
      callback = function()
        require("skkeleton").initialize()
      end,
    })
<
`initialize()` は DB 生成処理を細かく分割して進めるため、UI をブロックしませ
ん。また、一度 DB が生成されれば、次回起動時からは既存の DB を開くだけで即座に
利用できます。

DB ファイルはどこに保存され、どのように再生成されますか~
                                                      *skkeleton-faq-database*
`stdpath("cache")/skkeleton`（|skkeleton-config-databasePath| を設定した場合は
そのディレクトリ）に、辞書ごとの `<ハッシュ>.db` ファイルとして保存されます。
元の辞書ファイルのサイズや更新日時が変化すると、次回使用時に自動的に再生成され
ます。手動で強制的に再生成したい場合は、|skkeleton.update_database()| の第 3
引数 {force} に `true` を渡して実行してください。
>lua
    require("skkeleton").update_database(
      "~/.config/skk/SKK-JISYO.L", nil, true
    )
<
あるいはキャッシュディレクトリ内の `.db` ファイルを直接削除しても構いません
（次回使用時に再生成されます）。

変換マーカー（▽・▼）の描画が崩れる~

既定のマーカーである `▽` と `▼` は 'ambiwidth'（曖昧幅文字）の対象です。Neovim
と端末エミュレータやフォントの設定が一致していないと、文字幅のズレにより表示が
崩れることがあります。'ambiwidth' の設定を見直すか、曖昧幅ではない文字をマー
カーに指定してください。
>lua
    markerHenkan = "▿",
    markerHenkanSelect = "▾",
<
他の補完プラグインなどと干渉する~

有効化・無効化時の |User| イベントフックを使って、SKK の使用中のみ他のプラグイ
ンの機能を一時的に無効化できます。
>lua
    local group = vim.api.nvim_create_augroup("skkeleton-coc", {})
    vim.api.nvim_create_autocmd("User", {
      group = group,
      pattern = "skkeleton-enable-pre",
      callback = function() vim.b.coc_suggest_disable = true end,
    })
    vim.api.nvim_create_autocmd("User", {
      group = group,
      pattern = "skkeleton-disable-pre",
      callback = function() vim.b.coc_suggest_disable = false end,
    })
<
sticky key の挙動を eskk.vim に合わせたい~

かなテーブルに sticky key（`;`）を登録すると、促音の直後に変換開始位置を置く際
に「察し」を `;sass;si` と入力する必要があります。eskk.vim のように `;sass;i`
と入力したい場合は、かなテーブルではなくキーマップとして `henkanPoint` を登録
してください。
>lua
    require("skkeleton").register_keymap("input", ";", "henkanPoint")
<
端末モードで入力表示が崩れる~

端末バッファでは、未確定文字列の更新に `<BS>` を送出して書き直す方式をとってい
ます。そのため、動作中のアプリケーション側のマルチバイト文字や文字幅の扱いに
よっては表示が崩れることがあります。回避策として、コマンドラインで SKK 入力を
行って確定文字列のみを端末へ送るマッピングも利用できます。
>lua
    vim.keymap.set("t", "<C-y>", function()
      vim.api.nvim_feedkeys(vim.fn.input(""), "n", false)
    end)
<

skkeleton からの移行                                     *skkeleton-migration*

設定のキー名は skkeleton のものをそのまま使用できます。関数などの呼び出し方は
次のように変わります。

	skkeleton#config({...})           -> require("skkeleton").setup({...})
	skkeleton#register_kanatable      -> skkeleton.register_kanatable
	skkeleton#register_kanatable_file -> skkeleton.register_kanatable_file
	skkeleton#register_keymap         -> skkeleton.register_keymap
	skkeleton#initialize()            -> skkeleton.initialize()
	skkeleton#update_database         -> skkeleton.update_database
	skkeleton_indicator の setup(...) -> setup({ indicator = {...} })

仕様の違い~
- |skkeleton-config-databasePath| にはファイルではなくディレクトリを指定しま
  す。skkeleton が生成した Deno KV の DB ファイルは使用せず、新しい形式で DB
  を作成します。
- `sources` の `"deno_kv"` は `"skk_dictionary"` と同じものとして扱われます。
- `skkServer*` および `completionRankFile` は型の検証のみを行い、実際の処理で
  は使用しません。

非対応の機能~
- skkserv および Google 日本語入力（`sources` の `"skk_server"`、
  `"google_japanese_input"`）
- ddc.vim の補完ソースおよび `completionRankFile`
- YAML 形式・MessagePack 形式の辞書（JSON 形式の辞書には対応しています）
- `skkeleton#handle()`、`skkeleton#dangerously_clear_buffer_local_mappings()`

なお、同じ Neovim 環境で skkeleton と skkeleton.nvim を同時に有効にしないでく
ださい。
